# Почему в шапке только «В сети: N» и нет «Реальных» / «Онлайн»

## Причина

В шапке отображаются три показателя: **Зарегистрировано**, **Реальных**, **Онлайн**. Если видите только **«В сети: 1002»** (одно число), значит на сервере отдаётся **старая версия** файла `templates/base.html`.

В старой версии был один блок:
```html
<span class="header-stats">В сети: {{ total_users }}</span>
```

В актуальной версии (v1.0.3) в шапке должны быть три показателя и подгрузка с `/api/stats`.

## Что проверить на сервере

1. **Содержимое base.html**
   - На сервере откройте файл `templates/base.html` в каталоге приложения.
   - В нём должно быть:
     - Текст «Зарегистрировано» и «Реальных», «Онлайн» (не только «В сети»).
     - Строка: `<script src=".../header-stats.js">`.
     - Атрибут `data-stats-version="3"` у блока с классом `header-stats`.

2. **Файл скрипта**
   - Должен существовать файл `static/js/header-stats.js`, который запрашивает `/api/stats` и подставляет три числа в шапку.

3. **Деплой**
   - Убедитесь, что при деплое на agent.happybanana.solutions копируются актуальные:
     - `templates/base.html`
     - `static/js/header-stats.js`
   - После обновления файлов перезапустите приложение и сделайте жёсткое обновление страницы (Ctrl+F5).

## API

- **GET /api/stats** (без авторизации) возвращает:  
  `{ "total": N, "real": M, "online": K }`  
  Если этот ответ приходит, но в шапке по-прежнему одно число — значит в HTML отдаётся старый шаблон без скрипта.
